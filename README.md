# Harborline Ferries brand kit

The public brand kit for Harborline Ferries: colors, voice, audiences, and the new-customer welcome email.

If you are writing a welcome email, read `brand/audience.md` and `brand/icps.md`, then send `emails/welcome.html`. A welcome email with no audience named is written for the **first-time visitor**. The header is Hull Navy `#12263A`. The button is Signal Yellow `#E0A512` with a Hull Navy label. The mark is a single chevron, apex uppermost.

## Colors

- **Hull Navy** `#12263A` — headers, wordmark ground, text on yellow
- **Signal Yellow** `#E0A512` — buttons, chevron on navy, vessel names
- **Superstructure White** `#F2F4F6` — page and letter ground
- **Deck Grey** `#5B6B7A` — supporting text
- **Boot Topping Red** `#8C2F2F` — warning and cancellation only

## Voice, in one line

Open with the fact. Name the vessel and the quay. Write for one ICP, not for travelers in general. Sign off `See you on the quay`. Never write delighted, journey, or family.

## Company

Harborline Ferries Limited, Kelsall Quay. Vessels: Ardmore Rose, Kelsall Endeavour, Marnoch Star, Tolquin Spirit, Braewick Trader, Little Ossian. Terminals: Kelsall Quay, Nethergill, Tolquin Pier, Braewick Slip.
